# Project scope

Updated 2026-10-24 15:38 PDT.

This repository contains the completed first local, measured 2D spatial tumor investigation and interface, with evaluated protein reconstruction and conditional movement. The iPSC bioprocess laboratory was completed separately. The nanobody project remains on hold.

The owner authorized initial creation and push to **hiddenlif/spatial-tumor-lab**, with **private** visibility. The iPSC laboratory has its own repository, **hiddenlif/ipsc-bioreactor-lab**. Later scientific and product updates remain separate from this initial repository handoff.

The reduced input and its CC BY 4.0 attribution are included. The original 223 MB source CSV, runtime records, local environment files and interpreter caches are excluded from Git. The source CSV can be downloaded and verified with the retained preparation script. Frozen scientific source files and study results are unchanged by repository preparation.
