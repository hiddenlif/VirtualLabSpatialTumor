# Project scope

Updated 2026-10-26 08:44 PDT.

This repository contains the completed first local, measured 2D spatial tumor investigation and interface, with evaluated protein reconstruction and conditional movement.

The iPSC bioreactor laboratory has its own repository, [VirtualLabIPSCBioreactor](https://github.com/hiddenlif/VirtualLabIPSCBioreactor). Later scientific and product updates build on this release.

The reduced input and its CC BY 4.0 attribution are included. The original 223 MB source CSV, runtime records, local environment files and interpreter caches are excluded from Git. The source CSV can be downloaded and verified with the retained preparation script. Frozen scientific source files and study results are unchanged by repository preparation.
